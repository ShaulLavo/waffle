# Internal notes

Working notes for the people and agents who build Waffle. Nothing here is user documentation, and the public docs and the README never link into this folder. The files are test-run narratives, proof limits, triage, owner-machine runbooks and design for code that is not wired into `createRuntime()` (dirty admission, checkpoint pressure, startup memory admission, staged storage, local publication, workspace archive and export, the IndexedDB export design) that were once under `docs/`. An item leaves when it becomes an ADR or a public doc, or when the owner deletes it. Git history keeps everything that is deleted.
