# Remaining transfer

This private candidate is ready for review after Waffle's package layout and install API exist. The parent must bind the two source guests to Waffle's generic lazy installer, real canonical paths and aliases, shared build-tools and final verifier. No public package name, installer API, runtime adapter or host process bridge is invented here.

Find's execution predicates remain rejected. Xargs remains echo-only and rejects explicit commands, replacement and parallelism. Waffle owns any future child-process contract; this candidate does not add one. Historical wrappers and browser fixtures remain under `provenance/bash/` as transfer material and must be adapted to real Waffle APIs before becoming current package tests.
